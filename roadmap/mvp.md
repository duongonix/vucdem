# MVP Roadmap Location

The canonical, complete MVP execution plan lives at [`specs/roadmap/mvp.md`](../specs/roadmap/mvp.md).

Phase status records also live beside the canonical plan under
[`specs/roadmap/phases/`](../specs/roadmap/phases/). The root `roadmap/`
directory is retained only as a compatibility pointer so roadmap documentation
has one source of truth.
