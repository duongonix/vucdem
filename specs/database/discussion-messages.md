# Discussion Messages

## Purpose and path

`discussionMessages/{messageId}` stores the public, site-wide discussion room history.

## Fields

```ts
type DiscussionMessageDocument = {
	authorId: string;
	authorName: string;
	authorUsername: string;
	authorAvatarUrl: string | null;
	authorVerified: boolean;
	content: string;
	status: 'published' | 'removed';
	createdAt: Timestamp;
};
```

Message IDs are generated by Firestore. Author identity and timestamps are server-controlled.
Content is trimmed, required, plain text, and limited to 1,000 characters.

## Access and queries

Guests may read published messages through `GET /api/discussion`. Active authenticated Users may
create messages through `POST /api/discussion`. Browser Firestore access remains denied. The first
page reads the latest 60 messages by `createdAt`; subsequent polling requests only messages newer
than the latest received timestamp. The single-field `createdAt` index is sufficient.
