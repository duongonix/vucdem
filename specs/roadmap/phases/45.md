# Phase 45 — Reading continuity and safer discussion

Status: Completed

## Tasks completed

- Private per-user chapter reading progress and scroll percentage.
- “Đọc tiếp chương …” action on Story detail.
- Persistent device reader typography, width and night/blood/paper themes.
- Local crash-safe chapter autosave with explicit recovery and visible save state.
- Spoiler marking and click-to-reveal comments/replies.
- Trusted `@username` resolution and mention notifications.
- Native share/clipboard sharing for selected chapter excerpts.

## Files changed

- `src/lib/types/reading.ts`, `src/lib/services/reading.ts`
- `src/routes/api/reading-progress/[storyId]/+server.ts`
- Story reader/detail/editor and Comment components/service/validation/API.
- `specs/database/reading-progress.md`, `specs/database/comments.md`, `specs/features/comments.md`.

## Database changes

- Added private `users/{uid}/readingProgress/{storyId}` documents.
- Added `comments.isSpoiler`; legacy missing values are treated as `false` by the UI.

## Security changes

- Reading progress writes require a verified user and an existing published Chapter.
- Mention recipient UIDs are resolved by the trusted server, never accepted from clients.

## Important decisions

- Reader display settings and recovery drafts remain device-local.
- Firestore chapter state changes only through explicit save/publish actions, preventing autosave from
  accidentally unpublishing content.

## Known limitations

- Local recovery drafts do not synchronize across devices.
- Scheduled publishing, personalized discovery, achievements, moderation audit/rate limiting and
  trash recovery continue in the following extension phases.

## Verification

- Formatter, Svelte type-check and ESLint pass.
