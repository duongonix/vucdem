## Security Changes

- Editor cannot supply ownership, author snapshots, counters, or timestamps.
- Media uses signed owner-bound Cloudinary endpoints.
- `/write` uses the centralized protected-route boundary and safe login redirect.

## Specs Added or Updated

- Reused the canonical Write Post screen specification.
- Updated validation and Post storage documentation through Phase 9.

## Important Decisions

- Keep the MVP editor plain text rather than invent an unsanitized HTML or premature structured-editor schema.
- Display Story mode but leave it unavailable until Phase 18.
- Display “Không chọn cộng đồng” only; Community selection waits for Phase 24 persistence/permissions.
- Add only a minimal Post read surface required for successful publish navigation; this does not complete Phase 12.

## Known Limitations

- Story creation and Community selection are intentionally deferred to their requested phases.
- The minimal Post read destination omits Phase 12 voting, comments, owner actions, and full responsive detail composition.
- Live publish/media verification requires Firebase and Cloudinary credentials.
- Full integration/E2E testing remains deferred.
