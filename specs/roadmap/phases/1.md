## Important Decisions

- Self-host fonts from npm packages to avoid runtime dependency on a font CDN and preserve predictable Vietnamese rendering.
- Build interaction primitives on Bits UI so keyboard navigation, focus management, portal behavior, and ARIA semantics are not reimplemented manually.
- Use text-and-underline tabs, 0px card/control radii, thin borders, and compact actions to match the reference rather than default shadcn/SaaS styling.
- Honor reduced-motion preferences globally and use a controlled five-level z-index scale.

## Known Limitations

- This phase provides global primitives and a QA checkpoint, not the production application shell; header and sidebars begin in Phase 2.
- Light theme support is intentionally out of MVP scope.
